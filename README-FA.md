
# ⚡ SuPower

 > **سریع • سبک • ساده • بهینه**

 SuPower یک ابزار سبک و کاربردی برای ویندوز است که به شما امکان می‌دهد انجام یک عملیات را برای یک زمان مشخص یا پس از پایان یک شمارش معکوس برنامه‌ریزی کنید.

*[ENG version](https://github.com/ali-cheshomi/SuPower)
---

 ## ✨ ویژگی‌ها

 - ⏱️ **تایمر شمارش معکوس** — حداکثر `24:59:59`
- 🕐 **حالت ساعت** — برنامه‌ریزی عملیات برای یک ساعت مشخص
- 🔴 **خاموش کردن** — خاموش کردن خودکار ویندوز
- 🔄 **راه‌اندازی مجدد** — ری‌استارت خودکار ویندوز
- 📂 **باز کردن برنامه / فایل** — اجرای یک برنامه یا فایل
- ⏳ **نمایش زنده شمارش معکوس** — نمایش ساعت، دقیقه و ثانیه باقی‌مانده
- 🖥️ **System Tray** — اجرای برنامه به‌صورت مخفی و کم‌حجم در نوار سیستم
- 🎨 **رابط کاربری مدرن** — طراحی ساده، تمیز و شفاف
- ⚡ **سبک و بهینه** — مصرف کم CPU و RAM
- 📦 **قابل حمل (Portable)** — بدون نیاز به Runtime یا Framework اضافی

---

 ## ⏰ حالت‌های تایمر

 ### شمارش معکوس (Countdown)

 مدت زمانی را که می‌خواهید قبل از انجام عملیات سپری شود، مشخص کنید.

```
02:30:00
```

 حداکثر زمان قابل تنظیم:

```
24:59:59
```

 ### ساعت (Clock)

 زمان دقیق انجام عملیات را مشخص کنید.

```
02:12:27 → 2:12:27 بامداد
23:11:28 → 11:11:28 شب
```

 SuPower به‌صورت خودکار زمان باقی‌مانده را محاسبه می‌کند.

 ## 🔥 نحوه استفاده

 1. فایل `SuPower.exe` را اجرا کنید.
2. حالت **Countdown** یا **Clock** را انتخاب کنید.
3. زمان موردنظر را تنظیم کنید.
4. یک عملیات را انتخاب کنید.
5. تایمر را شروع کنید.
6. هنگامی که تایمر به `00:00:00` برسد، SuPower عملیات انتخاب‌شده را انجام می‌دهد.
