# ⚡ SuPower⏻

 > **Fast • Lightweight • Simple • Efficient**

 SuPower⏻ is a lightweight Windows utility for scheduling actions at a specific time or after a countdown.


*[FARSI version](https://github.com/ali-cheshomi/SuPower/blob/main/README-FA)
---

 ## ✨ Features

 - ⏱️ **Countdown Timer** — Up to `24:59:59`
- 🕐 **Clock Mode** — Schedule an action at a specific time
- 🔴 **Shutdown** — Automatically shut down Windows
- 🔄 **Restart** — Automatically restart Windows
- 📂 **Open App / File** — Launch an application or file
- ⏳ **Live Countdown** — Displays remaining hours, minutes, and seconds
- 🖥️ **System Tray** — Runs quietly in the Windows tray
- 🎨 **Modern UI** — Clean, simple, and transparent design
- ⚡ **Lightweight** — Low CPU and memory usage
- 📦 **Portable** — No additional runtime or framework required

---

 ## ⏰ Timer Modes

 ### Countdown

 Set how long you want to wait before performing the selected action.

```
02:30:00
```

 The maximum duration is:

```
24:59:59
```

 ### Clock

 Set the exact time when the action should occur.

```
02:12:27 → 2:12:27 AM
23:11:28 → 11:11:28 PM
```

 SuPower automatically calculates the remaining time.

 ## 🖥️ Requirements

 - **Windows 10**
- **Windows 11**
- **64-bit Windows**

 > No additional prerequisites are required.

---

 ## 🔥 Usage

 1. Run `SuPower.exe`
2. Select **Countdown** or **Clock** mode
3. Set the desired time
4. Choose an action
5. Start the timer
6. SuPower performs the selected action when the timer reaches `00:00:00`
